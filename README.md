# Artwork & Labeling Partners LATAM — sitio web

Sitio estático (HTML + CSS, sin build ni dependencias). La única llamada externa es Google Fonts (Montserrat).

```
index.html
styles.css
assets/   logos (SVG), trama de puntos (PNG), favicon
```

## GitHub Pages
1. Crea un repositorio y sube estos archivos a la raíz de la rama `main`.
2. En Settings → Pages → Source: "Deploy from a branch", rama `main`, carpeta `/ (root)`.

## Cloudflare Pages
1. Workers & Pages → Create → Pages → "Connect to Git" y elige el repositorio.
2. Framework preset: None · Build command: (vacío) · Build output directory: `/`.
3. Dominio propio: Custom domains → añade tu dominio.

## Antes de publicar
- Verifica los enlaces de Calendly, correo, celular y LinkedIn en `index.html`.
- Respeta las reglas del logo: no deformar, recolorear ni invadir su espacio libre.
